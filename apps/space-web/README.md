# Allfit Space — web

Public landing for Allfit Space at `space.allfit.one`. It is informational only:
it calls no API, stores nothing, sets no cookies and loads no analytics. The
Space product itself is the Expo app in `apps/space`.

Space is not publicly released, so the copy presents it as coming soon and never
as an available capability. The copy in `src/lib/content.ts` follows the Space
section of the main site (`allfitone-landing-page`); change both together.

## Local development

From the repository root:

```bash
bun run dev --filter=@allfitone/space-web
```

The app runs at `http://localhost:3002`. Every route is prerendered as static
content. Spanish lives at `/es` and English at `/en`, as on the main site; `/`
redirects temporarily to `/es`. Both languages live in `src/lib/content.ts`.

## Vercel

- Project name: `allfitone-space`
- Root Directory: `apps/space-web`
- Production branch: `main`
- Production domain: `space.allfit.one`
- Environment variables: none

Keep **Include source files outside of the Root Directory** enabled so the
workspace install resolves.

## Brand assets

`public/brand/allfit-one` is generated by the `allfitone-brand-assets` script of
`@allfitone/brand`. Regenerate it rather than editing the files by hand.
